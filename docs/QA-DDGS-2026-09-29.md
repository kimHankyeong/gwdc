# DDGS 검색 연동 QA

## 선택과 계약
- GitHub: https://github.com/deedy5/ddgs (MIT), PyPI ddgs 9.16.0.
- 비교 후보 SearXNG: https://github.com/searxng/searxng. 현재 Docker 엔진 미실행으로 Python에서 직접 운영 가능한 DDGS 채택.
- 실제 모델 설정: Kiln qwen3-32b. 검색은 모델 기능이 아니라 Node의 search_products Tool Calling이 로컬 DDGS API를 호출한다.
- Brave API 코드를 제거했다. DDGS backend도 duckduckgo로 고정하고 사용자/모델이 변경할 수 없게 했다.
- SEARCH_API_URL은 http://127.0.0.1:4479. 공개 인터넷에 검색 서버를 노출하지 않는다.

## 검증
- 실제 한국어 검색: DDGS 라이브러리 5개, 로컬 HTTP API 10개 결과. 쿠팡·G마켓 등의 실제 검색 제목과 URL 확인.
- Computer Use: 구매 화면에서 요청 생성→실제 Qwen 재개→검색 후보 10개 표시 확인. 테스트 fixture로 만든 후보가 아니다. 최종 재실행에서 조건·정책 예시·실제 후보 10개 표시까지 확인했다. 스크린샷 ddgs-qwen-candidates.png를 보관했다.
- 실제 실행에서 SEARCH_SCOPE_MISMATCH 발견: 범위 검사 유지, 도구 명세와 제한된 재교정 추가. 회귀 테스트로 교정 후 제공자 미설정 오류에서 종료 확인.
- 수집 허용 목록의 누락을 모델이 정책 차단이라고 오해하는 문제 발견: 후보가 있고 모의 금액이 없을 때 서버가 정해진 모의 금액 입력 안내를 반환하도록 수정. 회귀 테스트 추가.
- cross-site Origin 요청 403, 추출 API 404, backend 변경 요청 422, 8KB 초과 요청 413 확인.
- Node 11개 + Python 정책 평가 8개 통과. 전체 build 통과. Python pip check 통과.
- 같은 query/page 검색은 60초 메모리 캐시, 최대 256개. 동시 upstream 검색 최대 2개, 동일 검색의 진행 중 작업 병합.

## 구분할 한계
- 검색 결과는 상품 신원/가격 검증이 아니다. SOURCE_ALLOWED_HOSTS가 비어 있으므로 이번 브라우저 QA는 검색 제목·URL까지만 검증했고 원문 가격·평점은 미확인으로 표시했다.
- 배송비/단가는 사용자가 정하는 모의 입력이다. 검색 실패·원문 누락을 모델 생성 정보로 채우지 않는다.
- 상위 검색 엔진의 차단·검색 품질·트래픽 제한에 영향을 받는다. CAPTCHA나 차단을 우회하지 않는다. 5000명/200명 동시 실검색 SLA는 미검증이다.
- Sepolia 서명 지갑과 테스트 ETH가 아직 준비되지 않아 실제 감사 전체 QA는 미완료다. 검색 연동 성공을 체인 성공으로 표시하지 않는다.
