# 간결한 UI / QA

- Team 11, Workspace, 영문 장식 제목, 소개 영역, 반복 시뮬레이션 안내 제거.
- 구매·정책·기록 메뉴, 모의 주문 표시, 정책 읽기 전용/승인 체크 유지.
- 검색 후보는 이름·가격/평점 확인 여부를 우선 표시하고 출처 상세는 접기.
- 거래 진행 중 새 요청 폼 숨김. 서비스 설정 상태는 연결 설정에서 확인.
- 모바일 정책 패널을 펼칠 때 구매 입력과 입력 방식이 초기화되던 버그 수정.

## 검증

- TypeScript 검사 및 Vite production build 통과.
- Computer Use: 1440×1000 PC, 390×844 모바일, 320×740 좁은 모바일 캡처 검수.
- 가로 넘침 없음. 320px 하단 메뉴 높이 48px, 마지막 콘텐츠가 메뉴 위로 스크롤 가능.
- 기존 QA 요청의 실제 DDGS 후보 10개 표시, 후보 선택, 출처 상세 펼치기 확인.
- 승인 체크 없는 조건 승인 차단, 거래 중 정책 메뉴 비활성화 확인.
- 기록 메뉴 이동/복귀, 입력 방식 전환, 정책 펼치기 후 입력 보존 확인.
- 브라우저 수집 콘솔 오류 없음.
- 이번 QA는 UI 범위. 실제 Sepolia 송신/최종 확정은 검증하지 않음.

## Figma 리소스 확인

- Apple 공식 iOS 26 키트: https://www.figma.com/community/file/1527721578857867021/ios-and-ipados-26
- 라이선스: https://developer.apple.com/apple-design-resources-license/
- 라이선스 2A/2B의 목업 용도 및 소프트웨어 삽입 제한을 확인했다. Apple UI Kit/SF Symbols 원본 자산은 다운로드하거나 제품에 포함하지 않았다.
- 적용 UI는 기존 TypeScript/CSS 글래스 UI의 자체 구현이며 Figma 원본 오브젝트 직접 가져오기를 완료했다고 주장하지 않는다.

## 화면 사용설명서 추가

- 처음이신가요? 버튼에서 회색 말풍선 튜토리얼 실행. 현재 화면의 대상만 안내.
- 다음/이전/완료/닫기, Esc 종료 및 재실행 검증. 배경 조작은 모달로 차단.
- 1440px PC, 390px 모바일, 320px 좁은 화면 캡처 검수. 모바일 기본 9단계 위치 확인.
- 종료 후 구매 입력/방식 보존, 시작 버튼으로 포커스 복원 확인.
- 안내 중 자동 상태 갱신을 보류하여 대상이 사라지는 것을 방지.
- TypeScript 검사 및 Vite production build 통과.
