# AI 구매 에이전트 화면 모의 구현

직전 ASCII 설계를 클릭 가능한 모바일 우선 프로토타입으로 옮겼습니다. 실제 `frontend/` 앱과 API에는 연결되지 않습니다.

## 미리보기

프로젝트 루트에서 정적 서버를 실행한 뒤 `/opendesign/mockups/agent-purchase-flow/`을 엽니다. OpenDesign 뷰어에서는 이 폴더의 `index.html`을 선택합니다.

## 체험 경로

1. 시작 화면에 구매 요청을 입력합니다.
2. 조건 시트에서 수량을 비워 두면 에이전트의 추가 질문도 볼 수 있습니다.
3. 조건 승인, 예시 후보 근거, 최종 모의 주문 승인 시트를 거칩니다.
4. 영수증과 통합 기록 화면으로 이동합니다.
5. 내 정보에서 모의 정책 버전을 변경하거나 처음 상태로 돌아갑니다.

화면의 가격·판매처·감사 결과는 예시 데이터입니다. 실제 검색, 결제, 지갑 생성 또는 블록체인 트랜잭션은 없습니다. 진행 화면과 기록은 브라우저의 `localStorage`에 유지됩니다.

## 다시 빌드

`npm install` 후 `npm run build`를 실행하면 정적 미리보기에 쓰는 `app.bundle.js`가 갱신됩니다.
