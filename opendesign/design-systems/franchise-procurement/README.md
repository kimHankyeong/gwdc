# Franchise Procurement UI System

## Purpose

A Korean procurement and spending-control interface for franchise headquarters and branch staff. It presents approved limits, purchase requests, and transaction evidence in the order the user needs to review them.

## Source and scope

- Source: the approved GWDC Challenge B implementation brief in this task.
- Source: the React application under `apps/web/` in this repository.
- No external company brand guide, Figma file, image, logo, price list, or retailer research was supplied.
- All names, quantities, fees, and balances displayed in the application are marked as demonstration data.

## Index

- `tokens/colors_and_type.css` defines the application's canonical design tokens.
- `brand/voice-and-tone.md` defines Korean product copy.
- `brand/style-notes.md` defines page, layout, and state styling rules.
- `ui-kit-franchise-procurement/index.html` opens the interactive React application at the local Vite address.
