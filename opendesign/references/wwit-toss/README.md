## Application

- Strong amount typography and short action labels.
- Blue primary action, neutral gray background and white surfaces.
- Icon navigation and concise rows; bottom navigation on mobile, sidebar on desktop.
- Separate login/signup pages; clear empty states instead of disabled purchase forms.
- Original app components and Lucide icons, not a pixel clone or copied Toss artwork.
- Actual TypeScript implementation: frontend/src/app.css, ui.ts, main.ts, auth-page.ts.
